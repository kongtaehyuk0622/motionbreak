# MOTION BREAK – 웹 버전

카메라로 손·발 동작을 인식해 날아오는 물체를 터뜨리고 판자를 격파하는 체감형 게임(양덕용인대태권도).

- 바로 하기: https://kongtaehyuk0622.github.io/motionbreak/ (크롬·사파리, 휴대폰은 가로로)
- 이 저장소에는 **빌드된 게임 파일만** 있습니다(자동 배포). 소스 코드는 비공개입니다.
- 카메라 영상은 기기 안에서만 처리되며 어디에도 전송·저장되지 않습니다.
- 사용한 공개 소프트웨어: Flutter, Flame, Google MediaPipe Tasks Vision 0.10.35(Apache-2.0, `mediapipe/MEDIAPIPE_README.md`).
  전체 라이선스 고지는 `assets/NOTICES`.
